# Privacy Policy

## Summary

This personal OAuth app is used only by the repository owner for rclone access to their own Google Drive account.

## Data Handling

- No user data is collected from other users.
- No user data is sold or shared.
- OAuth credentials are used only to authenticate with Google APIs for personal file access.

## Data Retention

No external service operated by this repository stores personal data from other users.

## Contact

If needed, contact the repository owner through GitHub.
